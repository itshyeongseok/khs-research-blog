A Comparison between Framed-based and Event-based Cameras for Flapping-Wing Robot Perception
Tier 1 — 최상위
R. Tapia, J.P. Rodriguez-Gomez, J.A. Sanchez-Diaz, F.J. Ganan, I.G. Rodriguez, J. Luna-Santamaria, J.R. Martinez-de Dios, A. Ollero
IEEE/RSJ International Conference on Intelligent Robots and Systems (IROS), 2023, pp. 3025-3032 · DOI: 10.1109/IROS55552.2023.10342500
논문 요약
본 논문은 flapping-wing robot perception을 위한 frame 기반 카메라와 event 기반 카메라의 포괄적 실험 비교를 제시한다. DAVIS346 event 카메라를 포함한 7종 카메라를 E-Flap ornithopter에서 플랫폼 요구사항(무게, 크기, 전력), 비행 요구사항(dynamic range, motion blur), 비전 알고리즘 성능(코너 검출, VIO, 선 검출, 사람 검출)에 걸쳐 평가한다. 결과는 event 카메라가 전력 소비, dynamic range(>120 dB), motion blur 강건성에서 frame 카메라를 능가함을 보이며, event 기반 소프트웨어 생태계의 현재 성숙도 격차에도 불구하고 ornithopter 응용에 가장 유망한 센서임을 시사한다.

Introduction — 연구 동기 (클릭하여 자세히)
flapping-wing robot는 심한 진동, motion blur, 엄격한 payload 제약으로 인해 고유한 perception 과제에 직면한다. 카메라가 주된 센서 선택지이지만 frame 기반과 event 기반 카메라 중 무엇이 더 적합한지에 대한 합의가 없어, 본 논문은 이를 체계적으로 실험 비교하도록 동기화된다.
Related Works — 관련 연구 (클릭하여 자세히)
기존 ornithopter perception 시스템은 외부 센서나 기본적 온보드 카메라에 의존했고, 최근 연구들이 event 카메라를 탐구하고 있다. frame과 event 카메라 간 이론적 비교는 존재하지만, flapping-wing robot에 특화한 체계적 실험 비교는 수행된 바 없었다.
Method — 방법론 (클릭하여 자세히)
event 기반, monocular, stereo 구성을 아우르는 7종 카메라를 flapping 조건을 모사하는 세 개의 test bench와 E-Flap ornithopter 실제 비행 실험으로 평가했다. 비교 프레임워크는 플랫폼 요구사항, 비행 요구사항, 응용 의존적 성능을 다룬다.
Experiment — 실험 (클릭하여 자세히)
event 카메라는 frame 카메라 대비 더 낮은 전력 소비, 우수한 dynamic range, 더 높은 motion blur 강건성을 보였다. 비행 데이터 실험에서 APS와 DVS는 비슷한 성능을 달성했으며, event 기반 single-event 표현이 가장 빠른 입력률을 제공했다.
Discussion — 논의 (클릭하여 자세히)
결과는 우수한 dynamic range, motion blur 강건성, 경쟁력 있는 알고리즘 성능으로 인해 event 카메라를 ornithopter에 가장 적합한 센서로 시사한다. 다만 frame 기반 소프트웨어 생태계가 상당히 더 성숙해 있고, 온보드 처리 병목은 미해결 과제로 남는다.
Conclusion — 결론 (클릭하여 자세히)
본 논문은 체계적 실험 평가를 통해 event 카메라를 ornithopter perception에 가장 유망한 비전 센서로 확립한다. APS와 DVS가 유사한 알고리즘 성능을 달성했지만, dynamic range, motion blur 강건성, 전력 소비 측면의 event 카메라 고유 이점이 이를 선호되는 선택지로 만든다.
